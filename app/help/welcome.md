# Welcome

XCP Center Web manages your XCP-ng pools from a browser. It talks directly to XAPI on the pool master.

## Quick start

1. Add a pool with **Add pool** (master IP, user, password).
2. Browse the left tree: Infrastructure, Folders, Objects, Tags.
3. Select a VM and use the action buttons.

## Offline help

All articles live in `app/help/`. Add a `.md` file and restart to publish it.
