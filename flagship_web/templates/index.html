Credentials and XAPI sessions stay in server memory until disconnect, sign-out, expiry or restart. They are never saved to disk.

The system CA store verifies certificates by default. For a self-signed host, verify its fingerprint on the host console and paste it above. Changed certificates are refused.

VM operation

Force shutdown and reboot can lose data. Requests are not automatically retried. Folder updates replace only the folder key; inspect state if a request is interrupted.
